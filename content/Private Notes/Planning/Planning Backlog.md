# Planning Backlog

The team workflow described in `.claude/CLAUDE.md` assumes a planning hierarchy that
does not yet exist in the vault. The **workflow is in place; the infrastructure is
not.** This file tracks what needs building so the Showrunner and Continuity Auditor
have something real to check against.

## What exists
- `Planning/Major Arcs.md` — the fixed, DM-owned spine of four major arcs. ✅
- `Meta Notes/Corrections.md` — the corrections ledger. ✅
- `Meta Notes/*.md` — mechanical reference tables. ✅

## What is missing

### 1. `Planning/Charters/` — does not exist
`CLAUDE.md` names this as the home for minor arc, adventure, and session charters plus
alignment scorecards. The folder has never been created. **Consequence:** the
Showrunner cannot perform a vertical-fit check, because there is no parent charter
between a session and the major arc. Fit checks currently have to skip two levels
straight to `Major Arcs.md`.

### 2. Minor arc charters
Nothing connects the current Library of Layers storyline (roughly Sessions 20–28) to
Arc 2, *The Terramancers' Bargain*. The fit is obvious in practice —
[[Professor Sylas Thistlethorn]]'s Terramancy research serves "learn about
[[The Terramancers]], find them" — but it is nowhere written down.

### 3. Adventure charters
No adventure-level charter exists for the Library arc or anything before it.

### 4. Thread / hook / clock tracker
`CLAUDE.md` notes these are currently tracked inline in Session Notes `%% %%` blocks,
with a dedicated tracker page listed as "a future option, not something assumed to
exist." Worth revisiting — open threads are now numerous enough to be hard to audit:
Luwei's demand, the Aboleth eye, Operation Green Thunder, the self-mending desk,
Vase's no-books vow, the [[Ecclesia Solari]] / [[House Aurum]] tension.

## Recommended sequencing
1. **Do NOT retro-charter the Library arc mid-flight.** It is eight sessions deep and
   nearly finished; chartering it now steers nothing and costs real effort.
2. **Create `Planning/Charters/` and write the first real minor arc charter for
   whatever follows Session 28**, where it can actually shape decisions.
3. **Revisit the thread tracker** once the Library arc closes and its threads either
   resolve or carry forward.
4. Backfill earlier charters only if a continuity sweep shows it would have caught
   something.
